# BỐI CẢNH
Dự án KLEER: website TMĐT mỹ phẩm Unisex trên WordPress/WooCommerce, chạy Docker (nginx, php 8.2-fpm, mariadb 10.11, redis).
Theme: wp-content/themes/kleer-theme/. Plugin: wp-content/plugins/kleer-plugin/. Không sửa WordPress Core. Không dùng Elementor/WPBakery.
Chuẩn code: PHP theo PSR-12, JS ES6+. Mọi thay đổi qua Pull Request vào nhánh develop.

# LUỒNG VÀ NHIỆM VỤ
Luồng: L05 – Xử lý đơn hàng & Thông báo (HPOS Lifecycle)
Nhiệm vụ cụ thể (1 việc, 1 đầu ra): Khai báo tính tương thích HPOS cho plugin KLEER, tự động kích hoạt chế độ Custom Orders Table và cấu hình cờ đồng bộ nền (background sync) thông qua class Automattic\WooCommerce\Utilities\OrderUtil.

# ĐẦU VÀO
- Flow Card: docs/flows/L05-order-processing/flow-card.md
- Sơ đồ vòng đời: 5 trạng thái Pending payment, Processing, On-hold, Completed, Cancelled.
- Endpoint/Hook đã chốt:
  + Hook khai báo tương thích: `before_woocommerce_init`
  + Hook kiểm tra chuyển đổi: `woocommerce_after_register_post_type`
  + Lớp tiện ích HPOS: `Automattic\WooCommerce\Utilities\OrderUtil`
  + Các option WordPress: `woocommerce_custom_orders_table_enabled`, `woocommerce_custom_orders_table_data_sync_enabled`
- CSDL chuyên biệt HPOS: `wp_wc_orders`, `wp_wc_order_addresses`, `wp_wc_order_operational_data`, `wp_wc_orders_meta`.

# ĐẦU RA MONG ĐỢI
- Danh sách file cần tạo/sửa:
  + `wp-content/plugins/kleer-plugin/src/Services/HposService.php`
  + `tools/enable-hpos.sh`
- Khai báo class `HposService` với các phương thức:
  + `declare_compatibility()`: hook vào `before_woocommerce_init` gọi `FeaturesUtil::declare_compatibility('custom_order_tables', ...)`
  + `enable_hpos_storage()`: kiểm tra và kích hoạt cờ Custom Tables & background sync an toàn.
- Script bash `enable-hpos.sh` thực thi qua Docker container bằng lệnh WP-CLI: `wp option update` và `wp wc cot sync`.

# TIÊU CHÍ CHẤP NHẬN (Given–When–Then)
- Kịch bản 1 (Khai báo tương thích):
  - Given: Plugin kleer-plugin được kích hoạt trong hệ thống.
  - When: WooCommerce khởi tạo (`before_woocommerce_init`).
  - Then: WooCommerce ghi nhận kleer-plugin tương thích 100% với HPOS, không hiện cảnh báo incompatible plugin.
- Kịch bản 2 (Kích hoạt bảng chuyên biệt):
  - Given: Hệ thống đang chạy WordPress 6.x và WooCommerce >= 8.2.
  - When: Kích hoạt cài đặt HPOS qua OrderUtil hoặc WP-CLI.
  - Then: Giá trị `woocommerce_custom_orders_table_enabled` đổi thành `yes`.
- Kịch bản 3 (Bật đồng bộ nền):
  - Given: Đơn hàng mới được tạo hoặc sửa đổi.
  - When: Cờ `woocommerce_custom_orders_table_data_sync_enabled` bật là `yes`.
  - Then: Dữ liệu tự động đồng bộ giữa Custom Tables và các bảng legacy mà không làm gián đoạn thanh toán.
- Kịch bản 4 (Ngoại lệ khi chưa cài WooCommerce):
  - Given: WooCommerce chưa được kích hoạt hoặc bị tắt.
  - When: Service HPOS được gọi.
  - Then: Service tự động thoát an toàn, không gây lỗi Fatal error (kiểm tra `class_exists`).
- Kịch bản 5 (Ngoại lệ khi Orders Table chưa sẵn sàng):
  - Given: Các bảng `wp_wc_*` chưa được tạo trong CSDL MariaDB.
  - When: Kiểm tra `OrderUtil::custom_orders_table_usage_is_enabled()`.
  - Then: Ghi log cảnh báo và giữ nguyên chế độ lưu tạm tại `wp_posts` cho đến khi đồng bộ hoàn tất.
